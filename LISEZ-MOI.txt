INVESTPILOT PRO V7 — INSTALLATION ANDROID

CONTENU
- index.html : application
- manifest.webmanifest + sw.js : installation PWA et cache hors ligne
- icones 192/512

IMPORTANT
L’application conserve les données dans le stockage local du navigateur/appareil. Les données ne se synchronisent pas automatiquement entre plusieurs appareils. Exporte une sauvegarde JSON régulièrement.

INSTALLATION SUR ANDROID
1. Héberge le contenu de ce dossier sur une adresse HTTPS (par exemple GitHub Pages ou un hébergement web personnel).
2. Ouvre cette adresse dans Chrome sur Android.
3. Menu ⋮ > Installer l’application (ou Ajouter à l’écran d’accueil).
4. Lance InvestPilot depuis son icône.

IMPORTS
- Bricks : import incrémental. Les opérations déjà présentes sont conservées et les nouvelles ajoutées après détection des doublons.
- PEA / courtier : import Excel/CSV avec détection des colonnes Date et Montant et identification du type quand le libellé est explicite. Vérifie le résultat après chaque import : les formats des courtiers varient.
- Les cours ne sont pas connectés à une API de marché : renseigne la valeur actuelle de chaque placement dans sa fiche.
